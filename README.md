### 🚀 Current Focus
I'm currently building the **frontend for a statewide Result Management Platform for the Oyo State Ministry of Education**, serving secondary schools across the state. It features a multi-tier admin hierarchy (State → LGA → Zonal → School → HOD), per-subject/per-class result entry workflows, and a design system pulled from the Oyo State crest.

### 💼 Selected Projects

* **Oyo State Result Management Platform** — Building the frontend for a statewide secondary-school results system with a State/LGA/Zonal/School/HOD admin hierarchy and per-subject result entry workflows. *(in progress)*
* **INEC Voter Services App** — Expo + NativeWind React Native app for Nigeria's electoral commission, with live election results, party/candidate data, and a polling unit locator, integrated with a real civic election-data API.
* **RideLink** — Multi-modal transport super-app concept ("Uber for bikes, cabs, car-pools, and interstate travel"), built on React Native + Django Channels for real-time matching and tracking.

* **[StudyBuddy](https://github.com/EdwardIyanda1/studybuddy)** — Built a comprehensive student resource platform integrating course materials distribution and scheduling systems.
